Why TheAIcraftify?

TheAIcraftify is a public build log, not a finished resume. I'm a self-taught developer with limited formal education, learning AI, web development, app development and automation mostly through AI-assisted tools, documentation and trial and error.

I'm not claiming to be an expert. I'm someone who decided to learn in public, ship real (small) projects instead of only watching tutorials, and treat every mistake as part of the record. This site is where that consistency gets tracked — day by day, project by project.
